Security, Risk & Compliance

LLM Security Needs a Full Threat Model — Not Just Guardrails

A detailed technical guide from ByteByteGo lays out the complete threat surface for LLM-based applications: prompt injection, agent tool misuse, data exfiltration via model outputs, insecure retrieval pipelines, and cross-agent trust exploitation.

Why it matters: As enterprises deploy AI agents with tool access—web browsing, code execution, database queries—the security perimeter expands significantly. A prompt injection attack that causes an agent to exfiltrate data is not a content policy failure; it's an access control failure.

What should I do as a leader? Require a threat model review for any AI agent that has access to internal systems, APIs, or sensitive data.

Source: ByteByteGo, 2026-08-04 — LLM Security Basics: The Full Threat Model

Why it matters: Shieldstral's open-weight approach enables on-premises moderation—useful for data-residency requirements and organizations uncomfortable sending sensitive content to third-party moderation APIs.

Groundcover raised new funding around a pointed thesis: AI agent telemetry—traces, memory, evaluation data—should never leave your enterprise cloud.

Why it matters: Every AI agent interaction produces a trace. What should I do as a leader? Audit where your AI agent telemetry data currently flows and whether it falls under your data classification and residency policies.

Microsoft Research Releases Orchard: Open Framework for Agentic AI

Microsoft Research published Orchard, an open framework separating agent training from execution. It includes three reference implementations: Orchard-SWE (software engineering), Orchard-GUI (browser automation), and Orchard-Claw (personal assistant tasks), each showing measurable performance gains.

Why it matters: Training AI agents in realistic simulated environments before production deployment is a core unsolved challenge. Orchard's domain-specific recipes give enterprise teams verifiable performance baselines before deployment.

What should I do as a leader? Review Orchard for teams building internal AI agents, particularly for software engineering automation and process workflows.

Source: Microsoft Research, 2026-08-03 — Orchard: An Open Framework for Scalable Agentic AI
