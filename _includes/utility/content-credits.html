{%- comment -%} Visible content-role credits. Original pages identify their author. Reprints identify the source author(s) separately from Ted Tschopp's editorial/curatorial role. This prevents the republisher from being presented as the source author while retaining useful h-card markup for the actual author record. Usage: {% include utility/content-credits.html page=page %} {%- endcomment -%} {%- assign _credit_page = include.page | default: page -%} {%- assign _credit_categories = _credit_page.categories | join: '|' | downcase -%} {%- assign _credit_is_reprint = false -%} {%- if _credit_categories contains 'reprint' -%} {%- assign _credit_is_reprint = true -%} {%- endif -%} {%- if _credit_is_reprint -%} Source author: {% include utility/author-byline.html page=_credit_page prefix="" %} · Editor and curator: {{ site.profile.name | default: 'Ted Tschopp' }} {%- else -%} Author: {% include utility/author-byline.html page=_credit_page prefix="" %} {%- endif -%}
